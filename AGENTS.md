# AGENTS.md

`rq` is a Rust workspace for a JSON response projection language, a git-friendly Postman-compatible collection store, a CLI, and a Tauri desktop app. `README.md` is the design document; read its **Layout**, **Commands**, **Notes**, and **Secrets** sections before changing behavior.

## Start here

- `.codegraph/` is indexed. Use `codegraph explore "<symbol or question>"` (or `codegraph node <symbol>`) before grep/read. If it reports stale files, run `codegraph sync`.
- `crates/response-query/` — parser, byte scanner, projector, schema providers (OpenAPI, inferred, `Any`). Responses are scanned in place, never materialized into a DOM.
- `crates/collection/` — workspace model, Postman v2.1 import, per-request YAML store, sending, cURL preview.
- `crates/rq-cli/` — thin driver; package is `rq-cli`, binary is `rq`.
- `crates/desktop/` — Tauri shell. `ui/` is plain HTML/CSS/JS with no npm or bundler; Rust commands and state live in `src/main.rs`. `gen/schemas/` is generated by `tauri-build`; edit `tauri.conf.json` or `capabilities/default.json` instead.
- `examples/jsonplaceholder/` is data to open in the app, not a Cargo example. `openapi/fixture.json` is the committed spec; `queries/` holds saved queries.

## Commands

```powershell
cargo test --workspace                 # 119 tests, no network
cargo test -p response-query --test projection TEST_NAME
cargo test -p collection --test save TEST_NAME
cargo check --workspace --all-targets
cargo clippy --workspace --all-targets -- -D warnings
cargo fmt --all -- --check             # cargo fmt --all to fix

cargo run -p rq-cli -- check -q queries/orders/brief.query --spec openapi/fixture.json --operation listOrders
cargo run -p rq-cli -- ops --spec openapi/fixture.json
cargo run -p rq-desktop -- examples/jsonplaceholder
```

- There is no CI. The local clippy/fmt/test commands are the gate; the tree is currently clippy-clean and fmt-clean.
- If `cargo` is not on PATH in a fresh PowerShell, prepend `$env:USERPROFILE\.cargo\bin`.
- Desktop builds need `rc.exe`. README's SDK snippet takes the last directory under `bin`, which is `x86` on this machine, so its `$sdk\x64` path does not exist. Select the version directory explicitly:
  ```powershell
  $sdk = Get-ChildItem 'C:\Program Files (x86)\Windows Kits\10\bin' -Directory |
    Where-Object Name -like '10.*' | Sort-Object Name | Select-Object -Last 1
  $env:Path = "$($sdk.FullName)\x64;$env:Path"
  ```
- `ui/` is embedded at compile time, so rebuild `rq-desktop` after frontend edits; there is no hot reload.
- README's `openapi/service.json` / `getOrders` example is stale: the committed spec is `openapi/fixture.json` and its operations are `listOrders` and `getNode`.
- `examples/jsonplaceholder/environments/local.yml` points at `127.0.0.1:8788`, and no server ships with the repo. Without a local server, use the default collection URL (`jsonplaceholder.typicode.com`).

## Invariants

- **Secrets never reach a committed file.** Secret values belong only in `.secrets/` (gitignored). `store::render` is the single serializer; `store::write` and `store::save` scan for leaks and refuse to write. New export paths (cURL, copy-as-code, share) must go through the masking renderer; never add a direct file writer.
- **Saving is render + delta.** A draft that omits a secret value keeps the on-disk value; renames are paired so `.secrets/<slug>.env` moves instead of being deleted; files the tool did not write are not removed.
- **Response bodies stay in Rust.** Desktop `send` returns metadata and keeps bodies (at most 24); `project_body` returns projected text and truncates raw views at 512 KiB. Do not send a raw body over IPC.
- **Disk layout is the API.** `NN-` filename prefixes are the order (no manifest); `collection.yml`/`folder.yml` auth is inherited and `auth: none` opts out; the URL is base only, query parameters live in `params`, and `:segment` values live in `path_params`.
- **Query semantics.** The whole source must be one selection set starting with `{`; `*` only fills unlisted keys; `[id]` emits `null` for a missing key; field names may contain `- . @ $` and unicode. The scanner depth limit is 256 and recursive walks cost `O(bytes × depth)`; do not raise these casually.
- **Schema providers.** OpenAPI accepts JSON or YAML (`serde_norway`); `oneOf`/`anyOf` are a union of properties; self-referential models expand one level and then cut. `infer` turns empty arrays and all-null fields into `Any`.
- **Postman import.** Trust `url.raw` when present; also consuming `query[]` duplicates every parameter. Disabled params/headers round-trip as `disabled: true`; non-`raw` body modes are recorded, not guessed or converted.
- `.gitattributes` enforces LF. Keep it; one-file-per-request makes CRLF diffs expensive. `rq import` refuses to overwrite an existing collection directory.
